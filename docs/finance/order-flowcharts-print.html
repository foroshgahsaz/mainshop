۳) مدیر فروش در مقابل ادمین — دسترسی سفارش و پرداخت

مدیر فروش: مشاهده. ادمین: تغییر وضعیت، ویرایش پیش‌فاکتور، تمدید رزرو، حذف، مرجوعی.

        SM4[مشاهده جزئیات پرداخت]

۴) نمای کلی — سه مسیر

خلاصه وضعیت‌ها از ثبت تا ارسال برای فروشگاه، نماینده و عملیات ادمین.

flowchart TB
    subgraph Shop[مشتری — سایت]
        S1[pending] --> S2{پرداخت؟}
        S2 -->|آنلاین| S3[processing]
        S2 -->|COD| S4[pending تا ادمین]
        S2 -->|انقضا/لغو| S5[canceled]
    end
    subgraph Rep[نماینده]
        R1[draft] --> R2[proforma + رزرو]
        R2 --> R3{پرداخت کامل}
        R3 -->|بله| R4[processing]
        R3 -->|رزرو منقضی| R5[proforma بدون رزرو]
    end
    subgraph Ops[ادمین — پس از processing]
        O1[shipped] --> O2[delivered]
        O1 --> O3[canceled / returned]
    end
    S3 --> Ops
    R4 --> Ops
    S4 --> Ops
