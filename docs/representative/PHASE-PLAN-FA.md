# پایلان فازهای نمایندگی و پیش‌فاکتور (mainshop)

**آخرین به‌روزرسانی:** ۲۰۲۶-۱۰-۰۲  
**شاخهٔ مرجع deploy:** `master` (شامل mergeهای #۸۹ تا #۱۰۳)

---

## خلاصهٔ کارهای انجام‌شده

### فاز ۱ — پایهٔ پنل نماینده ✅

- پنل Filament در مسیر `/representative` با لاگین OTP.
- ریدایرکت بعد از ورود نماینده (بدون شکستن layout فروشگاه).
- مدیریت **مشتریان** متعلق به نماینده (ثبت، استان/شهر، آدرس، کد ملی).
- در **ادمین → کاربران**: ایجاد/ویرایش نماینده، پروفایل (استان، شهر، سقف رزرو).
- سایدبار و layout جدا برای نماینده؛ رفع خطاهای سایدبار ادمین.
- اصلاح `user_kind` / `is_representative` هنگام ایجاد کاربر.

### فاز ۲ — ویزارد پیش‌سفارش ✅

- migration سفارش نماینده: `representative_id`, `catalog_filters`, وضعیت `draft`.
- ویزارد Livewire: مشتری → خانواده → کارخانه → برند → قالب → محصول → جمع‌بندی.
- سرویس‌ها: `RepresentativeDraftOrderService`, `RepresentativeCatalogLookup`.
- ادغام خطوط تکراری همان محصول در جمع‌بندی.
- وضعیت **`proforma`** بعد از «ثبت پیش‌فاکتور»؛ نماینده فقط مشاهده، ادمین ویرایش باربری/پرداخت در جزئیات سفارش.

### رفع اشکال‌های مرتبط ✅

- تایمر OTP لاگین ادمین (قبل از درخواست کد).
- ترتیب LTR ورود OTP و فوکوس خودکار بین باکس‌ها.
- migrationها روی Laravel 12 / MySQL.

### فاز ۳ — در حال انجام 🔄

- **باربری نمایندگی** (جدول جدا از Shipping Methods فروشگاه): CRUD ادمین + انتخاب در جمع‌بندی پیش‌فاکتور.
- **درگاه پرداخت**: همان درگاه‌های فعال فروشگاه (زرین‌پال، تارا، …) در ویزارد نماینده.
- PDF پیش‌فاکتور، رزرو سخت موجودی، TTL، تمدید توسط ادمین (باقی‌مانده).
- اخبار، تیکت، محدودیت per-rep (در صورت نیاز).

**توجه:** تا قبل از فاز ۳، هنگام ایجاد پیش‌نویس، ارزان‌ترین روش ارسال فعال و `payment_method = online` به‌صورت پیش‌فرض ست می‌شود.

## دستور deploy روی سرور

```bash
git fetch origin
git checkout master
git pull origin master

composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan db:seed --class=IranLocationsSeeder   # فقط اگر استان‌ها خالی است
php artisan view:clear
php artisan optimize:clear
```
