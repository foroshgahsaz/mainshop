# بنر صفحهٔ اصلی — راهنمای خرید قسطی

## جایگاه و ارتفاع

بنر **بلافاصله زیر ردیف ۵ کارت طرح‌ها** در `home-hero-hub` قرار دارد و ارتفاع CSS آن با کارت‌ها یکی است (`132px` دسکتاپ، `145px` موبایل) — همان `border-radius: 16px`.

## فایل‌ها

| فایل | نقش | ابعاد تقریبی |
|------|-----|----------------|
| `home-how-to-buy.webp` | دسکتاپ / تبلت | **۱۲۸۰ × ۱۳۲** px |
| `home-how-to-buy-mobile.webp` | موبایل | **۸۲۸ × ۱۴۵** px |

در UI با `object-fit: cover` نمایش داده می‌شود؛ طرح را برای نوار باریک بهینه کنید.

## بعد از آپلود

فایل موبایل را در همین پوشه بگذارید و روی سرور deploy کنید؛ کش مرورگر را یک‌بار refresh سخت کنید.
